Bases du SEM

Pourquoi être en ligne ? Qu'est-ce que le DPL, le webmarketing, les KPI et l'USP ? Les fondations à poser avant tout le reste.

DPL Webmarketing USP KPI See-Think-Do-Care Showrooming

Le contexte numérique

cliquer pour replier

Selon les statistiques (lesechos.fr 2019) : 82,6 % des Français sont connectés, 43,8 millions utilisent internet quotidiennement, 55,6 % via smartphone et 29,1 % via tablette.

Ce taux de connexion énorme prouve que la communication digitale est un outil indispensable pour les entreprises qui veulent être visibles. C'est l'action de dématérialiser les supports de communication.

Parts de marché des moteurs de recherche (monde) :

  • Google : 92,46 %
  • Bing : 2,64 %
  • Yahoo! : 1,46 %
  • Baidu : 1,23 %
  • Développer la communication digitale = Développement de la Présence en Ligne (DPL)
  • Google domine très largement — viser ce moteur en priorité

Qu'est-ce que le DPL ?

cliquer pour replier

Le DPL consiste à adopter la stratégie adaptée à votre transformation digitale.

Il englobe :

  • Le web
  • Les réseaux sociaux
  • Les terminaux portables (smartphones, tablettes)

Et fait intervenir d'autres canaux innovants :

  • Chatbot, voicebot
  • Big data, blockchain
  • Réalité virtuelle

Le Webmarketing

cliquer pour replier

Le webmarketing = utiliser Internet pour se faire connaître et/ou développer son activité. C'est la version numérique du marketing traditionnel.

Il comprend :

  • Un site internet pertinent et actif (produits/services dès la page d'entrée)
  • Le référencement naturel
  • Une présence en ligne active
  • Du contenu reflétant votre savoir-faire
  • Des profils sur les réseaux sociaux ciblés
  • Des campagnes cross-canal avec planning éditorial

Le webmarketing améliore le flux d'informations et fait de toi un acteur de ta e-réputation ou personal branding.

Quatre catégories du webmarketing :

  1. Webmarketing stratégique — analyse des attentes, veille, positionnement
  2. Création de trafic — SEO, pub en ligne, emailing, jeux-concours
  3. Analyse des performances — visibilité, trafic, ventes
  4. Fidélisation — animation, refonte, communauté, emailing
⚠ Attention DPL ≠ Webmarketing ! Le webmarketing vise une rentabilité sur une activité. Le DPL vise la diffusion et le façonnage d'une identité numérique.

L'objectif : être présent

cliquer pour replier

Pourquoi être présent sur Internet ? Pour que la cible sache que tu existes. Mais attention : il ne s'agit pas de crier partout sur le cyberespace au risque de te décrédibiliser.

La première action du DPL est d'identifier l'objectif de la stratégie. Demande-toi ce que tu dois proposer pour atteindre tes objectifs commerciaux/communications.

  • Avoir une idée précise de ce que tu veux réaliser → définir efficacement les priorités
  • Rationaliser pour ne pas être dépassé par les événements

Élaboration d'une stratégie

cliquer pour replier

Une bonne stratégie doit allier concepts de base stables et état d'esprit tourné vers l'avenir (innovations).

Trois règles d'or :

  1. Définir ce que tu attends d'Internet et fixer des objectifs réalistes
  2. Utiliser l'analyse d'audience pour mesurer ce qui fonctionne
  3. Rester à jour, s'adapter aux évolutions du secteur
⚠ Attention Le site web est souvent la première chose qui vient à l'esprit, mais ce n'est pas forcément par-là qu'il faut commencer. L'important est de décider ce que tu veux que tes internautes puissent faire, puis de créer un espace pour ça.

Étapes d'élaboration stratégique :

  1. Définir clairement les objectifs — donne une direction
  2. Définir la vision de l'entreprise — la "mission" en une phrase
  3. Identifier l'USP — argument unique de vente, ce qui te démarque

Exemples d'objectifs USP :

  • Augmenter les ventes → générer plus de trafic vers le site (pub payante, contenu)
  • Augmenter la notoriété → réseaux sociaux pour exprimer valeurs et personnalité
  • Développer la liste mailing → indiquer clairement ce que les inscrits recevront (contenu exclusif, infos VIP)

Définir les objectifs (KPI)

cliquer pour replier

Les KPI = mesures quantifiables qui concentrent l'attention sur les chiffres importants pour atteindre les objectifs commerciaux.

Ils aident l'équipe à comprendre comment les progrès sont suivis et mesurés.

Critères d'un bon KPI (méthode SMART) :

  • Spécifique
  • Mesurable
  • Réaliste
  • Pertinent
  • Limité dans le temps

Questions à se poser pour valider un KPI :

  • Est-il suffisamment spécifique ?
  • Peut-il être mesuré ?
  • Tes employés peuvent-ils le réaliser ?
  • Quel impact sur l'objectif global ?
  • Quand doit-il être atteint ?

Définir l'USP — comportement utilisateur

cliquer pour replier

La segmentation de la clientèle aide à choisir où concentrer les efforts. Quatre étapes dans un processus d'achat, décrites par le framework See-Think-Do-Care :

  • See — voir (awareness)
  • Think — penser, considérer
  • Do — agir, acheter
  • Care — prendre soin, fidéliser

Quand l'étape "See" se passe en magasin physique, on appelle ça le showrooming.

Point de contact = n'importe quelle étape où un visiteur entre en contact avec l'organisation. Outil efficace pour développer fidélité et confiance. Quand un client rencontre un point de contact à plusieurs reprises (ex : pub en ligne), cela crée une valeur importante et une relation durable avec la marque.

  • DPL = stratégie identité numérique (≠ rentabilité du webmarketing)
  • Étapes : objectifs SMART → vision → USP → KPI
  • Framework See-Think-Do-Care pour comprendre le parcours client
  • Un point de contact répété bâtit la confiance

Le référencement

SEO, SEA, SMO : trois piliers, trois logiques. Comprendre le SERP, le ranking, les enchères, le CPC max et la longue traîne.

SEM SEO SEA SMO SERP Ranking CPC max Longue traîne

SEM, SEO, SEA, SMO — qui est qui ?

cliquer pour replier

Le référencement génère du trafic et influe sur le nombre de visiteurs. Le SEM (Search Engine Marketing) consiste en l'optimisation du référencement.

Trois notions le composent :

  • SEO — référencement naturel et son optimisation
  • SEA — référencement payant et son optimisation
  • SMO — référencement social et son optimisation

Référencement naturel : quand quelqu'un saisit des mots-clés, la page de résultats contient une liste de résultats naturels (non payants), généralement au centre. Ce sont les meilleurs résultats selon le moteur. Impossible d'acheter sa place dans les résultats naturels.

Référencement payant : mêmes mécaniques que le naturel, mais positionné en priorité moyennant finance.

Le SERP = la page de résultats qu'un moteur affiche après une recherche, classée par pertinence et fiabilité.

Le ranking = la position dans les résultats des moteurs de recherche.

  • 3 piliers du SEM : structure technique du site · contenu · popularité
  • SEO = long terme, gratuit, organique
  • SEA = court terme, payant, immédiat
  • SMO = réseaux sociaux
⚠ Attention Trop souvent, SEM et SEO sont confondus. Le SEO n'est qu'une partie du SEM (la partie organique). Ces termes peuvent être incohérents entre Google et les autres cabinets.

SEO — Référencement naturel

cliquer pour replier

SEO (Search Engine Optimization) = "Optimisation pour les moteurs de recherche". Ensemble des techniques pour améliorer la position d'un site web dans le SERP. Aussi appelé référencement naturel ou organique.

Un site est bien optimisé s'il est dans les premières positions sur les requêtes souhaitées.

Le SEO agit sur ce que les moteurs valorisent :

  • La fréquentation
  • La notoriété
  • La situation géographique
  • Le code
  • Les contenus uniques, attrayants et pertinents

Trois objectifs SEO :

  1. Conversions — transformer les visiteurs en clients payants
  2. Intérêt et interaction — persuader les gens d'interagir avec le contenu
  3. Acquisition — trouver de nouveaux clients

Planification SEO

cliquer pour replier

Établir un plan SEO :

  1. Lister les étapes (ex : recherche de mots-clés, performance, etc.)
  2. Prioriser les étapes
  3. Définir un coût pour chaque étape — rester réaliste
  4. Date limite par tâche pour travailler régulièrement
  5. Faire évoluer le plan dès qu'il y a des changements (activité, algorithmes, fonctionnalités)
★ Règle d'or Le contenu de ton site doit être conçu pour tes internautes, pas pour les moteurs de recherche.

Mots-clés

cliquer pour replier

Le choix des mots-clés est la base du SEO. Trois choses à prendre en compte :

  1. La fréquence — nombre de fois qu'un mot est recherché. Termes très fréquents = difficulté à se différencier.
  2. La concurrence — un site important a des chances d'apparaître. Si tu démarres, vise des mots avec moins de concurrence.
  3. La pertinence — les mots doivent correspondre à ce que tu offres.

Seul un petit nombre de mots-clés ont un volume de recherche très élevé. Beaucoup ont un faible volume → c'est la longue traîne en SEO.

→ Exemple "Fraises" → beaucoup de concurrence. "Se faire livrer des fraises bio à Périgueux" → mot-clé de longue traîne avec des résultats plus immédiats. Pour une PME, la longue traîne offre souvent de meilleures opportunités.
⚠ À éviter L'accumulation de mots-clés (keyword stuffing) : répéter inutilement les mots-clés. Effet contraire à celui voulu — pénalisation par les moteurs.

4 recommandations pour optimiser le SEO dans la durée :

  • Se renseigner sur le fonctionnement des moteurs
  • Surveiller les changements et leur impact
  • Trouver l'inspiration sur d'autres sites
  • Parler à ses clients

SEA — Référencement payant

cliquer pour replier

SEA (Search Engine Advertising) : type de publicité où les annonceurs enchérissent pour diffuser leurs pubs à côté des résultats selon les mots-clés saisis.

Avantage : les internautes qui cliquent sont pro-actifs — ils cherchent activement le produit. Différent du marketing traditionnel qui diffuse à des gens potentiellement intéressés.

Les liens sponsorisés permettent d'acheter de l'espace pub via un système d'enchères d'annonces textuelles. Les annonces ressemblent beaucoup aux résultats naturels.

Enchères & CPC max

cliquer pour replier

À chaque recherche, les annonceurs entrent en compétition. Le processus dure quelques millisecondes.

L'enchère = montant maximal qu'un annonceur est prêt à dépenser pour un clic. C'est le CPC max.

L'annonceur ne paie que lorsque quelqu'un clique sur son annonce → "paiement par clic". Grande différence avec presse / panneaux d'affichage.

Niveau de qualité : note de 1 à 10 qui évalue à quel point ton annonce se rapproche de la recherche. Les annonces à haut niveau de qualité peuvent décrocher des emplacements plus hauts même avec des enchères plus basses. Tu ne peux pas simplement "acheter ton succès".

  • SEA = enchères + paiement par clic (CPC max)
  • Pertinence + qualité comptent autant que le prix
  • Critères mots-clés sponsorisés : pertinence, trafic, concurrence
  • Inclure CTA, offre limitée, mot-clé recherché dans le titre

Page de destination

cliquer pour replier

Les moteurs prennent aussi en compte la première page que les gens voient après avoir cliqué sur une annonce. C'est la page de destination (landing page).

Une page de destination cohérente avec le mot-clé recherché améliore la pertinence et donc le niveau de qualité.

Référencement local

Pour les entreprises avec boutique physique : annuaires, fiches Google, GPS et SEO local pour capter les clients à proximité.

SEO local Annuaires locaux SEA local GPS Fiche établissement

Qu'est-ce que le local ?

cliquer pour replier

"Local" = entreprises avec une boutique physique qui proposent leurs services aux gens vivant à proximité ou de passage dans la région.

Indexer géographiquement = les pros du SEO l'appellent SEO local. Il faut se construire une présence locale en ligne.

Avant tout : vérifie que les détails sur ton emplacement sont consultables. Adresse, carte interactive, téléphone, horaires.

Annuaires locaux

cliquer pour replier

Les annuaires locaux sont excellents pour entrer en contact avec les clients à proximité.

Créer une fiche dans un annuaire inclut : nom commercial, adresse, numéro de téléphone.

⚠ Attention Beaucoup d'annuaires exigent que ton entreprise possède un local ou ait une zone de service locale. Les entreprises virtuelles sans contact direct ne sont généralement pas acceptées.

Tu dois choisir :

  • Le nom de l'entreprise (identique partout en ligne)
  • L'adresse physique (boîtes postales et lieux partagés généralement refusés). Toujours sous la même forme sur chaque annuaire.
  • Numéro de téléphone — local, avec indicatif régional. Éviter les numéros verts/gratuits.

Cibler en priorité :

  • Les grands moteurs : Yahoo!, Bing, Google (versions locales)
  • Les grands annuaires locaux
  • Les réseaux sociaux
  • Les sites d'avis spécialisés (parfois sectoriels)

Le SEO local comporte aussi : horaires, description, photos, vidéos, catégories.

★ Conseil Si tu es inscrit dans plusieurs annuaires (recommandé), garde une trace dans une feuille de calcul. Si nom/adresse/numéro change → mets toutes les fiches à jour immédiatement.

Publicité locale (SEA local)

cliquer pour replier

La publicité locale permet de montrer tes annonces uniquement aux personnes à proximité.

Canaux locaux :

  • Moteurs de recherche — afficher seulement dans certaines régions
  • Réseaux sociaux (Facebook, LinkedIn) — pages pro et pubs payantes pour cibler localement
  • Annuaires locaux & sites d'avis — proximité des utilisateurs

Applications mobiles

cliquer pour replier

Deux usages des technologies mobiles :

  1. S'assurer que ta fiche & ton site fonctionnent parfaitement sur mobile, avec coordonnées. Profiter de la fonction GPS pour orienter les utilisateurs.
  2. Application dédiée que les utilisateurs installent. Peut utiliser le GPS pour envoyer des notifications quand le client approche du magasin (promos, événements, prise de rendez-vous, etc.).

La publicité locale + GPS permet de cibler les bons clients, au bon moment, et désormais au bon endroit.

SEO local

cliquer pour replier

Tu dois expliquer aux moteurs de recherche ce que tu entends par "local" !

Ajoute du contenu utile qui aide à identifier ta position géographique :

  • Descriptions, photos, vidéos
  • Événements connus dans ta région
  • Articles avec offres spéciales invitant les clients locaux

Au fur et à mesure que tu ajoutes des informations locales, les moteurs identifient la pertinence pour les recherches locales.

  • Inscription cohérente sur les annuaires (Google, Bing, Yahoo) + sites d'avis
  • Mêmes infos partout — sinon tu pénalises ton SEO local
  • SEA local : ciblage géographique précis + GPS pour timing parfait
  • Contenu géolocalisé sur ton site → meilleure visibilité locale

Site Web

Nom de domaine, page d'accueil, ergonomie, navigation, CTA, dark patterns, contenu, backlinks. Tout pour construire un site qui convertit (et reste éthique).

URL TLD UX / UI Look & feel Fil d'Ariane CTA Dark Pattern Backlink Balises Meta

Rappel : qu'est-ce qu'un site web ?

cliquer pour replier

Un site web = ensemble de pages web et ressources reliées par des liens hypertextes, accessibles via une adresse URL, le tout enregistré sous le même nom de domaine.

Un site contient textes et multimédia, hébergé sur un serveur web, accessible via internet ou intranet.

Référencement site web :

  • Indexation — inscription dans les moteurs et annuaires
  • Positionnement — actions et techniques pour améliorer la position dans les résultats

Le nom de domaine

cliquer pour replier

Élément primordial de la méthode SEO. C'est ce que les internautes tapent dans leur navigateur pour te trouver.

Étapes à respecter :

  1. Vérifier qu'il est disponible
  2. Choisir un nom court, pertinent, direct, mémorable
  3. Si .com / .fr indisponible, choisir un TLD alternatif (ex : .org pour les ONG)

Page d'accueil

cliquer pour replier

Première page que les internautes verront. C'est la vitrine de ton magasin.

Elle doit refléter l'identité de marque, composée de 3 éléments :

  • Identité visuelle (logo, couleurs, typographie)
  • Voix (façon dont l'entreprise s'adresse à sa cible)
  • Valeurs

Maintenir une identité cohérente renforce ton image, préserve ta crédibilité et démontre ton authenticité.

Le look and feel doit être identique sur toutes les pages : palette, typo, visuels.

⚠ Attention L'organisation des informations sur la page d'accueil et la cohérence visuelle sont des éléments importants en SEO.
★ Aide SEO Utilise des titres descriptifs et uniques pour chaque page. Inclus les mots importants pour aider les moteurs à comprendre le contenu.

Ergonomie

cliquer pour replier

Définition : étude du travail visant à améliorer les conditions et accroître la productivité. En digital, ça signifie permettre aux visiteurs de trouver facilement ce qu'ils cherchent.

Deux approches techniques :

  • UX Design — User Experience, design de l'expérience utilisateur
  • UI Design — User Interface, design de l'interface (couleurs, mise en page, formes)

L'aspect

cliquer pour replier

La première impression est capitale. Les sites web épurés sont devenus le standard. Les plus visités au monde ont tous convergé vers une chose : la simplicité.

Les internautes lisent textes foncés sur fond clair. Vérifie que tes textes sont lisibles. Attention à :

  • La police de caractères
  • La taille (recommandé : au moins 16 pt)
  • La couleur

Évite les polices manuscrites sur le web.

→ Pratique Le logo se positionne dans la barre de navigation, à gauche ou au milieu en haut de chaque page. Raison : la plupart des internautes parcourent les pages en formant un Z.

Navigation

cliquer pour replier

La navigation guide les internautes. Organisation cohérente et logique. Les internautes s'attendent à ce que les choses fonctionnent d'une certaine manière.

Règles :

  • Ne pas obliger à scroller trop pour voir l'essentiel
  • Utiliser titres et listes à puces pour aider au survol rapide
  • Boutons "À propos" ou "Contact" sur chaque page

Le fil d'Ariane permet au lecteur de se retrouver et de naviguer de page en page sans le menu.

Les liens hypertexte (texte ou images) redirigent vers d'autres pages au clic.

Pour les sites avec beaucoup de pages, intégrer un champ de recherche dans la barre de navigation.

→ Stat 56 % des visiteurs utilisent le menu pour naviguer. Source : Metapress.

Call to Action (CTA)

cliquer pour replier

Les CTA amènent les internautes à poser une action désirable. Représentés par des boutons : "Ajouter au Panier", "Lire Plus".

Ils servent à passer les étapes du tunnel de conversion.

Exemple e-commerce :

  1. Visiter une page produit
  2. Ajouter au panier
  3. Finaliser la vente

Les CTA peuvent aussi simplement fluidifier la navigation sans utiliser le menu (ex : "En savoir plus" → page À propos détaillée).

Dark Pattern (deceptive design)

cliquer pour replier

Le Dark Pattern = design trompeur utilisé sur le web (notamment e-commerce) pour pousser l'utilisateur à une action qu'il n'aurait pas faite autrement.

Basé sur des techniques de manipulation psychologique : tromper l'utilisateur pour qu'il clique, s'inscrive ou achète sans s'en rendre compte.

⚠ Exemple type — Amazon Prime Amazon attire les acheteurs vers un bouton jaune pour finaliser le paiement, mais ce bouton les fait souscrire à Amazon Prime gratuitement pendant une période de test. Pour ne pas souscrire, un lien peu visible en bas à gauche permet de continuer sans s'abonner.

Les moteurs de recherche essayent actuellement de réprimer ce genre d'activité.

Contenu — fond & forme

cliquer pour replier

Sur le fond, il faut :

  • Éviter d'être vaniteux ou commercial — pas de discours de vente brut, pas trop de jargon
  • Expliquer, vulgariser, aider — montrer comment tu réponds aux besoins des clients
  • Contextualiser, être inclusif — raconter une histoire, témoignages, vidéos clients, possibilité de laisser des avis
  • Imager, épurer — chaque seconde compte, les visiteurs lisent en diagonale

Construis ton site en gardant en tête tes objectifs pro ET les envies de tes visiteurs.

Les crawlers analysent l'organisation et le contenu, recoupent les paraphrases et le plagiat pour évaluer l'apport du site et améliorer (ou non) sa position dans le SERP.

★ Aide SEO Le contenu du site doit être unique.

Sur la forme :

  • Balises Meta et titre — cachés dans le HTML, aident le moteur à comprendre la page
  • Meta description — 2 phrases courtes, renforce le titre avec les mêmes mots-clés
  • En-têtes (H1, H2…) — visibles, structurent le contenu
  • Texte — ne pas répéter trop souvent l'expression d'indexation (risque de spam)

Backlink (liens entrants)

cliquer pour replier

Les backlinks (liens entrants/externes) = liens situés sur d'autres sites qui pointent vers le tien.

Comparable à des votes de confiance : si beaucoup de liens pointent vers ton site, ça signifie que beaucoup de gens pensent que tu offres un contenu de qualité.

  • Identité de marque cohérente sur toutes les pages
  • UX/UI : épurer, simplifier, taille texte ≥ 16pt
  • CTA bien placés pour fluidifier le tunnel de conversion
  • Éviter les Dark Patterns — éthique + sanctionné
  • Balises Meta + Backlinks = piliers SEO techniques

Réseaux sociaux

SMO, SMM, nudging, e-réputation : comment utiliser les médias sociaux comme un levier de marketing sans tomber dans les pièges classiques.

SMO SMM Nudging E-réputation PAO Hydratation

Pourquoi les médias sociaux ?

cliquer pour replier

Les médias sociaux (Facebook, Twitter, etc.) sont un moyen supplémentaire de mieux faire connaître l'activité et de créer des liens avec les clients.

  • SEO pour ces médias = SMO (Social Media Organization)
  • SEA pour ces médias = SMM (Social Media Marketing)

À quoi ça sert :

  • Mise en pratique du nudging (paternalisme libéral) — rester présent dans l'esprit des clients par des publications régulières
  • Établir une relation de confiance avec le public — diminue la résistance, génère un état motivationnel
  • Promouvoir l'activité indirectement — quelqu'un dit du bien de toi a plus de poids que toi-même
  • Identifier la e-réputation — la façon dont les internautes interagissent avec ta marque

Types de médias sociaux

cliquer pour replier

Il faut classer tous les sites par catégorie pour savoir auxquels donner la priorité.

La dimension : les principaux réseaux (Facebook, Twitter, YouTube, Instagram, LinkedIn) comptent énormément d'utilisateurs (Facebook : +1 milliard de membres dans le monde). Tes clients y ont probablement un compte.

Outre ces géants : sites plus spécifiques dédiés à des publics particuliers (TripAdvisor, La Fourchette…). Moins d'utilisateurs, mais plus pertinents pour ton secteur.

Objectif du média

cliquer pour replier

Trois grands objectifs :

  1. Réseaux personnels — rester en contact avec famille/amis. Tu peux y entrer en tant qu'entreprise, mais avec un ton léger, intéressant, utile (pas axé ventes)
  2. Réseaux de partage de contenu — fournir des informations détaillées : faits, chiffres, graphiques, avis
  3. Réseaux professionnels — entreprise, recherche d'emploi, recrutement

Plan SMO

cliquer pour replier

1) Sélectionner les médias sociaux — quels réseaux sont les plus utilisés par tes clients ?

  • Évaluer le rapport production/entretien
  • Identifier les avantages spécifiques de chaque réseau
  • Déterminer les objectifs d'usage
  • Compte Pro vs particulier ?

2) Hydrater / peupler le média — remplir un compte qui ne contient pas encore de données.

  • Créer un profil ou page d'accueil sur chaque média
  • Données pro avec coordonnées pro (e-mail, adresse)
  • Ajouter détails, photos, vidéos chaque fois que possible

3) Initialiser les actions — faire connaissance avec les voisins.

  • Inclure le réseau existant sur les médias sociaux
  • S'adresser aux membres comme dans la "vraie vie"
  • Impossible de forcer les relations — ça prend du temps
  • Inviter les clients existants par liens, publicité, promotions

4) Élargir le réseau (PAO) — planifier les initiatives ponctuelles/récurrentes.

  • Préparer un programme — quel contenu publier ?
  • Identifier le moment idéal (immédiat/différé)
  • Sur quel réseau ?
  • Quelle personne de la société sera chargée ?
⚠ Attention Si ce n'est pas intégré au fonctionnement de l'entreprise, le SMO ne sera pas mis en œuvre et va même produire l'effet inverse.

Mesurer son réseau

cliquer pour replier

Les réseaux sociaux ont leurs propres données. Mais se connecter à chaque réseau séparément peut être complexe et chronophage.

Solution : outils de gestion des médias sociaux qui agrègent les mesures.

⚠ Inconvénient Ces outils ne suivent que l'activité sur les réseaux eux-mêmes. Pour un suivi complet, utiliser des outils indépendants d'analyse Web (Google Analytics).

Pièges récurrents

cliquer pour replier

Les erreurs à éviter absolument :

  • Être autocentré — tes followers s'intéressent déjà à toi. Offre une expérience plaisante, conserve leur attention. Suivi des commentaires, sois compréhensif, prévenant, cohérent. Réponds aux réclamations. Un commentaire négatif n'est pas une catastrophe — c'est l'occasion de montrer ton sérieux.
  • Se disperser — il y a tellement de réseaux que les occasions sont quasi illimitées. Mais ça prend du temps. Concentre-toi sur les plus importants.
  • Poster irrégulièrement — un compte sans actu depuis des mois donne l'impression que l'entreprise a fermé. Les boîtes prospères communiquent beaucoup.
  • SMO = organique · SMM = payant (sur les réseaux)
  • Sélectionner → Hydrater → Initialiser → Élargir (PAO)
  • Outils de gestion + Google Analytics pour mesurer
  • Éviter : autocentrage, dispersion, irrégularité

L'e-mail marketing

cliquer pour replier

L'e-mail marketing (emailing) = démarche de marketing direct qui consiste à envoyer du courrier électronique à plusieurs destinataires d'une base de données de manière ciblée.

Ce n'est pas du spam : on envoie des informations et offres pertinentes à des personnes qui ont déjà accepté.

L'e-mail marketing construit la fidélité et l'engagement client à coût très réduit. Il fonctionne bien sur mobile.

Légal — RGPD

cliquer pour replier

Pour toute récupération d'infos, les gens doivent te donner la permission de collecter leurs données personnelles (nom, e-mail, téléphone) afin de leur envoyer des emails commerciaux.

En application des lois sur la prospection commerciale, tu dois :

  • Préciser ton identité
  • Donner la possibilité de s'inscrire ET de se désinscrire eux-mêmes
  • Répertorier la date, l'heure et la source du consentement
⚠ Rappel légal Il est illégal d'envoyer des emails à des citoyens UE sans leur consentement. L'achat de listes de courriels est interdit.

Préparation

cliquer pour replier

1ère étape : fixer des objectifs. Présenter produits/services, faire venir des visiteurs, distribuer un coupon générant 10 ventes minimum, etc.

Une fois l'objectif connu, établir la liste des personnes intéressées :

  • Leur demander — proposer aux clients en magasin d'envoyer bons et offres en échange de leur email. Sur le site : formulaire d'abonnement
  • Identifier les différents publics et personnaliser les communications

On établit une base de données client avec une adresse e-mail par contact, plus nom, adresse postale, etc.

Logiciels & formulaire

cliquer pour replier

Les logiciels d'emailing fournissent un formulaire en ligne à intégrer au site (copier-coller un morceau de code). Les visiteurs s'inscrivent, la donnée est transférée automatiquement à la base.

Le formulaire d'inscription doit :

  • Rester court et facile à remplir
  • Fournir un double opt-in (confirmation par mail)

Design Pattern (Template) : les modèles d'e-mail = publipostage / publimail.

Les Smart Templates = moteur dynamique qui analyse ton site et génère des modèles personnalisés optimisés pour la conversion.

Beaucoup lisent leurs mails sur mobile : mobile-friendly obligatoire. Les outils permettent de prévisualiser sur différents appareils.

Planification (PAO)

cliquer pour replier

Important : capacité de planifier le moment d'envoi. Envoi immédiat ou jour/heure ultérieure.

Les outils suivent ce que font les gens à réception : ouverture, clics. On peut enregistrer ces préférences pour envoyer aux moments les plus pertinents.

Segmentation

cliquer pour replier

De nombreux services offrent une fonction de personnalisation qui place du contenu pertinent dans un modèle d'email selon les centres d'intérêt.

La segmentation divise le marché cible en segments de clients = groupes homogènes susceptibles d'utiliser un produit/service.

En ciblant chaque groupe avec un email personnalisé, tu augmentes les chances que les internautes lisent et cliquent.

Contenu — nomenclature & texte

cliquer pour replier

Les deux choses que les clients voient en premier :

  1. Le nom dans le champ "De"
  2. L'objet de l'email

Utilise un nom et email clairs qui identifient l'entreprise. Les gens ouvrent les emails de gens qu'ils reconnaissent et en qui ils ont confiance.

Objet réussi :

  • Court et simple — moins de 10 mots
  • Infos les plus utiles et pertinentes
  • Si possible, personnalisé ou localisé
⚠ Mots qui déclenchent les filtres anti-spam Éviter : "gratuit", "remise", "rappel", "promos", le symbole €, les points d'exclamation.

Texte : les internautes lisent en diagonale. Le contenu doit être concis et droit au but.

  • Paragraphes courts (1 à 3 phrases)
  • Centrés sur une seule idée
  • Liens vers articles plus longs
  • Rédaction convaincante et engageante
  • Inclure des CTA dans les liens
  • Mettre en évidence avec texte en gras et design

Obligations légales

cliquer pour replier

En bas de chaque email :

  • Lien pour se désabonner
  • Lien pour changer ses préférences
  • Lien pour mettre à jour ses infos de contact
  • Informations légales de l'entreprise
⚠ À savoir Un courrier électronique n'est pas chiffré par défaut et peut être transmis. Attention aux données perso et aux listes de diffusion.

Tu ne peux pas :

  • Demander un mot de passe pour la désinscription
  • Forcer un sondage avant désinscription

Respecter cette interdiction augmente la délivrabilité.

Test A/B

cliquer pour replier

Le test A/B = créer deux versions d'un email pour voir celle qui fonctionne mieux.

On regarde l'email avec :

  • Taux d'ouverture plus élevé — nb d'ouvertures / nb d'envois
  • Taux de clic plus élevé — engagement avec le contenu

On peut tester : objets, fréquence, contenu, images. Tester d'envoyer le mardi vs samedi, hebdomadaire vs mensuel.

★ Conseil Ne pas noyer les gens sous les emails. Toujours offrir la possibilité de recevoir moins de mails (ex : résumé mensuel) plutôt qu'ils se désinscrivent.

Créer des pages d'accueil spécifiques (A&B) pour les campagnes : quand quelqu'un clique, il atterrit sur une page web pertinente.

Performance — métriques clés

cliquer pour replier

Statistiques utiles en marketing par email :

  • Taux de livraison — emails parvenus jusqu'au serveur de messagerie des abonnés
  • Taux d'ouverture — ratio (ouverts / reçus). Évalue l'efficacité de la ligne d'objet
  • Taux de clics (CTR) — pourcentage de personnes qui cliquent sur les liens. Évalue l'efficacité globale
  • Taux de réactivité — clics totaux / emails ouverts. Vision plus réaliste de l'engagement
  • Taux de conversion — destinataires / personnes qui concrétisent l'objectif
  • Taux de rejet (rebond) — pourcentage non remis. Deux types :
    • Soft bounces (rejets temporaires) — boîte pleine, taille max serveur
    • Hard bounces (rejets permanents) — emails bloqués ou adresse incorrecte. Permet d'identifier les adresses à supprimer
  • Taux de désinscription — destinataires qui ont cliqué sur le lien de désinscription
  • Opt-in obligatoire (RGPD), achat de listes interdit en UE
  • Objet : court (<10 mots), évite "gratuit/€/!"
  • Contenu : paragraphes courts, 1 idée, CTA clair
  • Métriques : ouverture, CTR, réactivité, conversion, bounces
  • Test A/B systématique pour optimiser

Droit à l'oubli

Comment limiter (sans jamais totalement effacer) sa trace numérique : RGPD, CNIL, curing, déréférencement, outils et démarches concrètes.

Curing RGPD / GDPR CNIL Déréférencement Web profond Web surfacique

Disparaître d'internet ?

cliquer pour replier

Vouloir disparaître des inter-réseaux peut sembler tentant. Mais à part renoncer à toute forme de vie sociétale, il est totalement impossible de disparaître des inter-réseaux.

La question légitime : quels usages sont indispensables, quels usages sont facultatifs ?

On parle de curing = suppression du contenu gênant en recourant au droit à l'oubli.

Aujourd'hui facilité par :

  • La RGPD (GDPR)
  • Des organismes comme la CNIL

Rappel : Droit à l'oubli

cliquer pour replier

Selon Wikipédia : le droit à l'oubli est un concept de l'Union européenne. Il permet à un individu de demander le retrait sur le web d'informations qui pourraient lui nuire.

Deux applications :

  • Droit à l'effacement — retrait sur le site d'origine
  • Droit au déréférencement — suppression dans les moteurs (sans toucher à la source)
→ À noter Le droit à l'oubli fait partie des directives RGPD.

Il intervient pour un individu concerné par un contenu sur internet qui souhaite demander le retrait. Idem pour les réseaux sociaux (censure ou retrait définitif).

⚠ Limites On ne peut pas tout supprimer. La RGPD : sous réserve de certaines conditions, et notamment de l'intérêt du public à avoir accès à l'information.

Google précise : il établit un équilibre entre vie privée et intérêt du grand public. Refus possible pour : escroqueries financières, fautes professionnelles, condamnations criminelles, conduite publique des fonctionnaires.

Rechercher ses traces

cliquer pour replier

Identifier et lister les plateformes détentrices d'information sur l'identité numérique.

  1. Lister les éléments déclaratifs connus — toutes les plateformes où tu as mis volontairement de l'info
  2. Identifier les dépendances — comptes liés, connexions sociales (les "Se connecter avec...")
  3. Parcourir les logiciels d'aide à la navigation — les navigateurs gardent des infos même après suppression locale
  4. Parcourir les profondeurs du Web :
    • Moteurs (Google, Yahoo, Bing), professionnels (societe.com, dnb.com), personnels (Webmii, namechk), archives (Web.archive)
    • Web surfacique par accès direct
    • Proxy publics/privés : LinkedIn, Twitter, Facebook, Instagram, Pinterest…
    • Web profond par accès indirects
⚠ Approche biaisée Le profilage du compte utilisé pour faire la liste censure les résultats. Les informations rayonnent par leur propagation.

Outils utiles :

  • E-réputation : social-searcher.com, brandyourself.com
  • SEM (vu dans le cours)
  • Analyseurs de traces : haveibeenpwned.com, pipl.com, stalkface.com

Agir

cliquer pour replier

Avant les mesures irrévocables, sauvegarder ce qu'on souhaite conserver !

Une fois la liste prête :

  • Supprimer entièrement les comptes
  • Au pire : effacer un maximum, changer pseudos/infos par des données fictives, verrouiller le compte récalcitrant
  • Désactiver la collecte de données
  • Supprimer les données logicielles
  • Effectuer sur tous les supports (PC, téléphone, tablette, TV, IoT…)
⚠ Délai de grâce On dispose généralement d'un délai pour changer d'avis. La suppression réelle peut prendre jusqu'à 90 jours.

Outils & services qui aident :

  • Projets publics qui répertorient les démarches : justdelete.me, justdeleteaccount.com
  • Services d'accompagnement (payants) : Accountkiller.com, Semji.com
  • unroll.me — liste les abonnements automatiquement (mais hors UE pour cause RGPD)

La suppression pure et simple ne détruira pas immédiatement toutes les données ou résultats. Mais avec le temps, elle les rend moins susceptibles d'apparaître.

Tester

cliquer pour replier

Important de tester la persistance des données plusieurs jours plus tard pour constater la disparition progressive. On réeffectue les étapes de recherche préalablement mises en œuvre.

  • Disparaître totalement = impossible. Curing = limiter ses traces
  • RGPD encadre, CNIL accompagne
  • Effacement (source) ≠ Déréférencement (moteur de recherche)
  • Workflow : Rechercher → Sauvegarder → Agir → Tester
  • Délai de grâce ≈ 90 jours avant suppression effective
